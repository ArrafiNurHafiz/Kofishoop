# Panduan Penulisan Proposal

## Jenis Proposal dan Strukturnya

---

### A. Proposal Skripsi / Tesis / Disertasi

**Struktur standar:**
```
HALAMAN JUDUL
HALAMAN PERSETUJUAN (jika diminta)
DAFTAR ISI

BAB I PENDAHULUAN
  1.1 Latar Belakang Masalah
  1.2 Identifikasi Masalah
  1.3 Batasan Masalah
  1.4 Rumusan Masalah
  1.5 Tujuan Penelitian
  1.6 Manfaat Penelitian

BAB II KAJIAN PUSTAKA
  2.1 Landasan Teori
  2.2 Penelitian Relevan / Terdahulu
  2.3 Kerangka Berpikir
  2.4 Hipotesis (jika ada)

BAB III METODE PENELITIAN
  3.1 Jenis Penelitian
  3.2 Waktu dan Tempat Penelitian
  3.3 Populasi, Sampel, dan Teknik Sampling
  3.4 Variabel Penelitian
  3.5 Definisi Operasional Variabel
  3.6 Teknik dan Instrumen Pengumpulan Data
  3.7 Validitas dan Reliabilitas
  3.8 Teknik Analisis Data

DAFTAR PUSTAKA
LAMPIRAN (kisi-kisi instrumen, draft kuesioner, dll.)
```

---

### B. Proposal Penelitian Hibah / Kompetitif

**Struktur umum (adaptasi sesuai template pemberi hibah):**
```
1. Judul Penelitian
2. Identitas Pengusul
3. Ringkasan / Executive Summary (≤500 kata)
4. Latar Belakang dan Permasalahan
5. Tujuan dan Manfaat
6. Tinjauan Pustaka
7. Metode Penelitian
8. Jadwal Penelitian (tabel Gantt)
9. Anggaran Biaya (rincian dan justifikasi)
10. Tim Peneliti dan Pembagian Tugas
11. Daftar Pustaka
12. Lampiran (CV pengusul, surat pernyataan, dll.)
```

---

### C. Proposal Proyek / Kegiatan

**Struktur:**
```
1. Nama/Judul Kegiatan
2. Latar Belakang (masalah yang direspons)
3. Tujuan
4. Manfaat
5. Sasaran/Target Peserta
6. Waktu dan Tempat
7. Susunan Acara / Timeline
8. Kepanitiaan / Struktur Tim
9. Anggaran Biaya
   - Pemasukan (sumber dana)
   - Pengeluaran (rincian)
10. Penutup
Lampiran: Formulir, MoU, dll.
```

## Panduan Bagian Kritis Proposal

### Latar Belakang Masalah
Pola yang terbukti efektif:
```
[Konteks makro] → [Kondisi ideal] → [Kondisi aktual/masalah] 
→ [Dampak masalah] → [Upaya yang ada + kelemahannya] 
→ [Solusi yang diusulkan] → [Pernyataan penelitian]
```

Contoh kalimat pembuka yang kuat:
- "Di era digitalisasi yang semakin masif, kemampuan literasi data menjadi kompetensi esensial..."
- "Tingginya angka dropout mahasiswa (X%) di perguruan tinggi Indonesia menunjukkan bahwa..."

### Rumusan Masalah
- Tulis dalam bentuk **pertanyaan** yang spesifik dan dapat dijawab
- Mulai dengan: "Bagaimana...", "Apakah...", "Seberapa besar...", "Faktor apa..."
- Jumlah rumusan = jumlah tujuan = jumlah simpulan (konsistensi)

✅ Baik: "Bagaimana pengaruh metode flipped classroom terhadap hasil belajar mahasiswa pada mata kuliah Algoritma Pemrograman?"
❌ Kurang: "Apakah metode pembelajaran berpengaruh?"

### Tujuan Penelitian
- Awali dengan kata kerja operasional: menganalisis, mengidentifikasi, menguji, mengembangkan, mendeskripsikan, membandingkan
- Harus menjawab rumusan masalah secara langsung

### Kerangka Berpikir
- Narasi yang menjelaskan hubungan antar variabel
- Diikuti bagan/diagram kerangka konseptual
- Jelaskan arah hubungan yang dihipotesiskan

### Anggaran Biaya
Komponen umum:
| Komponen | Keterangan |
|---|---|
| Honorarium | Peneliti, asisten, narasumber |
| Bahan habis pakai | ATK, bahan lab, konsumsi |
| Peralatan | Sewa/beli alat |
| Perjalanan | Transport, akomodasi |
| Lain-lain | Publikasi, seminar, laporan |

Tips: Setiap item harus ada **justifikasi** — mengapa dibutuhkan dan bagaimana perhitungannya.

### Jadwal Penelitian
Format tabel Gantt (bulan × aktivitas):

| No | Kegiatan | Bln 1 | Bln 2 | Bln 3 | Bln 4 |
|----|----------|-------|-------|-------|-------|
| 1 | Studi literatur | ✓ | | | |
| 2 | Penyusunan instrumen | ✓ | ✓ | | |
| 3 | Pengumpulan data | | ✓ | ✓ | |
| 4 | Analisis data | | | ✓ | ✓ |
| 5 | Penulisan laporan | | | ✓ | ✓ |

## Kesalahan Umum dalam Proposal

- ❌ Latar belakang terlalu panjang tanpa arah yang jelas
- ❌ Rumusan masalah dan tujuan tidak sejajar
- ❌ Metode tidak sesuai dengan rumusan masalah
- ❌ Tinjauan pustaka = daftar definisi, bukan sintesis
- ❌ Anggaran tidak realistis atau tanpa justifikasi
- ❌ Tidak ada penelitian terdahulu (terkesan tidak membaca literatur)
